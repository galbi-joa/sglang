> 동아리 제출용 요약. 멘토/친구/선배의 주장을 코드로 검증 → 정정 → 벤치를 production과

## 0. 한 줄 요약
멘토/친구가 던진 두 의문("trtllm fp8 비교가 안 된다", "FlashMLA는 prefill 전용 커널이
없다")을 **전부 코드로 검증**해서 잘못된 결론을 바로잡고, 벤치를 production과 일치시켰다.
더불어 CP/타이밍 로직의 **실제 버그 3개**를 잡았다.

## 1. fp8 sparse_decode "Missing TRTLLM-GEN kernel" 해결
- 증상: trtllm을 fp8 KV로 맞추니 `Missing TRTLLM-GEN kernel`.
- **근본 원인**: 레이아웃 오류가 아니라 **cubin 디스패치 실패**. flashinfer가
  `q dtype == KV dtype`을 강제(`ICHECK_EQ`). KV만 fp8로 바꾸고 query를 bf16으로 둔 게 원인.
- 친구의 "fp8/fp8 불가능, bf16으로 되돌리자" 결론이 **틀렸음**을 확인
  (production은 `mla_quantize_and_rope_for_fp8`로 q도 fp8화).
- 수정: trtllm query도 fp8로 → 정상. (commit `3a9567a`)
- 실측(fp8/fp8): decode에서 trtllm 2.4~2.75배 빠름. trtllm KV가 fp8가 되며 더 빨라져
  speedup이 이전(bf16)보다 더 벌어짐.

## 2. 벤치 CP/테스트 로직 감사 → 실제 버그 3개 수정 (commit `7fa2681`)
1. `run_sparse_prefill`이 batch `b`를 무시 → B=4/16 행이 가짜 중복. → 양쪽 커널에 b 전달.
2. `run_prefill_ragged`의 cross-check가 실패 커널을 가드 없이 재호출 → sweep 전체 중단 가능.
   → `r.ok` 가드 + `_safe_call`.
3. sparse_prefill에서 flashmla만 head pad, trtllm 안 함 → 비-128 head 불공정. → trtllm도 pad.

## 3. "FlashMLA는 prefill 전용 커널이 없다"(선배) 검증 → 부분만 맞음
- cmake/op/소스 추적 결과: `flash_mla_sparse_fwd`(→ op `sparse_prefill_fwd`,
  `sm100/prefill/sparse/fwd/...`)는 **전용 sparse prefill 커널이 실재**. 선배 주장은 틀림.
- 단, DSA는 fp8 KV + (KV ≥ 512×q)인 경우 **decode 커널(`flashmla_kv`)로 prefill**하는
  휴리스틱이 있음 → 선배가 본 게 이 경로. (dsa_backend.py:2234–2250)

## 4. DSA(V3.2) 전체 디스패치 확정 + 문서화
- `forward_extend`/`forward_decode`의 모든 분기, use_mha 게이트, prefill 자동선택 휴리스틱,
  각 backend가 부르는 실제 API를 라인 단위로 추적.
- `trtllm_ragged_attention_deepseek`는 V3 전용이 아니라 **DSA의 dense(use_mha) 분기**임을
  확인 (V3/V3.2 혼동의 출처).
- 산출물:
  - `dsa_dispatch_report.md` (중국어, file→function→line + Mermaid 3장, commit `14ae9c4`)
  - `bench_implementation_v2.md` (sparse_decode fp8 정합 전말, commit `73b6d88`)
  - `bench_implementation.md`에 3 regime 수학적 차이 + 각 test 구현법 추가 (commit `bc056bf`)

## 5. 배운 것
- `Missing kernel`은 **레이아웃 오류 ≠ 디스패치 실패**. 후자면 dtype/shape 조합 cubin 부재가 원인.
- 멘토/선배/친구의 주장도 곧이 받지 말고 **코드로 검증**할 것 — 오늘 두 건 다 절반만 맞았다.
- 마이크로벤치는 **production의 실제 호출(API·dtype·shape)과 일치**시켜야 의미가 있다.
